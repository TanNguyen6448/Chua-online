# Chùa Online 🛕

Web game 3D: vào chùa, hóa thân thành sư thầy, ngồi tụng kinh trước tượng Đức Phật,
thỉnh chuông, thắp hương, đi dạo quanh hồ sen và vườn thiền.

Mở file `index.html` trên trình duyệt là chơi được ngay — không cần cài đặt gì.

## Đưa lên GitHub + Vercel (để ai cũng chơi được)

**Bước 1 — Tạo repo trên GitHub**
1. Vào https://github.com/new
2. Đặt tên repo, ví dụ `chua-online`, chọn Public, bấm **Create repository**
3. Trên trang repo mới, bấm **uploading an existing file**, kéo thả `index.html`
   (và file này `README.md` nếu thích) vào, bấm **Commit changes**

**Bước 2 — Deploy lên Vercel**
1. Vào https://vercel.com, đăng nhập bằng tài khoản GitHub (**Continue with GitHub**)
2. Bấm **Add New → Project**, chọn repo `chua-online`, bấm **Import**
3. Không cần chỉnh gì thêm — bấm **Deploy**
4. Xong! Vercel cho một link công khai dạng `chua-online.vercel.app` — gửi ai cũng mở được,
   kể cả ở Việt Nam.

Mỗi lần muốn cập nhật game: upload file `index.html` mới lên GitHub là Vercel
tự deploy lại bản mới.
